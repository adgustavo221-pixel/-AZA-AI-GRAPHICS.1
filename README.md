# AZA AI GRAPHICS

Painel experimental do projeto AZA AI GRAPHICS.

## Módulos planejados
- FPS Manager
- Graphics Manager
- Smart Scanner

## Estado atual
Esta versão é somente uma interface web demonstrativa. Ela não se conecta ao PS4, não detecta jogos e não altera FPS ou configurações do console. A arquitetura nativa será planejada e validada separadamente.

## Executar
Com Node.js instalado:
```bash
npm install
npm run dev
```

Gerar build web:
```bash
npm run build
```

**Aviso:** esta interface web não é um PKG de PS4 e não pode ser convertida em PKG apenas renomeando arquivos.
